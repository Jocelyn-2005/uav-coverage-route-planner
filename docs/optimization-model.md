# 优化模型

Coverage Generation 固定产生一组不可拆分的 coverage lanes。Route Optimization 只决定 lane 的访问顺序和正反方向，目标是以较低计算成本减少起点、lane 之间和返航的障碍感知连接距离。

当前采用最近可达 lane 的 Greedy 启发式。障碍代价来自建筑水平安全缓冲区外的二维最短路。覆盖率和安全可行性是验收条件，不参与多目标加权。

本分支不求全局最优，不实现 Exact、2-opt、Or-opt、GTSP/MILP，也不联合优化扫描线生成与访问顺序。任务时间、重复覆盖、转弯和能耗可作为未来研究指标，但只有实测收益大于计算成本时才考虑加入。
