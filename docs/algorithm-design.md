# 低算力算法设计

规划流程固定为：构造有效搜索地面，生成 `0°/90°` Global Scanline 候选，优先选择轻量 footprint 覆盖面积更大的方向，再比较 lane 数和基础路径长度；随后使用 Greedy 决定 lane 顺序和执行方向，以二维障碍最短路连接并均匀生成飞控航点。

扫描线间距由相机 footprint 和旁向重叠率决定。航线被搜索区、建筑占地和排除区裁剪。连接、避障和返航航段保持独立分类，但视频检测可全程运行。

最终覆盖验证使用垂直向下相机的地面 footprint 与每个 patch 求交。每个 patch 必须达到配置阈值；未达到的部分按 `unreachable_ground` 报告。本分支不运行候选补全循环，也不进行建筑墙体遮挡投影，因此结论仅代表二维自由地面几何覆盖。

设计目标是确定性、低内存和短运行时间，不宣称全局最优。高级局部搜索和精确优化不进入本分支的运行路径。
